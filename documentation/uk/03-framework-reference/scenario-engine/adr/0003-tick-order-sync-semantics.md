# ADR-0003: Семантика міжмодульної синхронізації за порядком тактів (не snapshot)

> 📖 **In English:** [documentation/en/03-framework-reference/scenario-engine/adr/0003-tick-order-sync-semantics.md](../../../../en/03-framework-reference/scenario-engine/adr/0003-tick-order-sync-semantics.md)

**Статус:** заглушка. Повністю буде написано на Кроці 13 (test_track_synchronization).

## Стислий виклад рішення

Рушій тактує екземпляри та доріжки у порядку їхнього оголошення; читає SharedState заново при кожному виклику `state_get()`. Записи доріжки A видимі доріжці B, якщо B тактується ПІСЛЯ A у тому самому такті. На наступному такті всі записи видимі всім доріжкам.

## Розглянуті альтернативи

- **Семантика snapshot** (записи на такті N → видимі на такті N+1): детермінованіша, але контрінтуїтивна («чому я не бачу того, що щойно записав?»). Відхилено.
- **Дворежимна модель** (прапорець `instant_cross_track_sync` на кожен рецепт): додає складність без чіткої переваги. Відхилено.

## Наслідки

- Залежить від порядку: автори рецептів повинні оголошувати доріжки у послідовності «виробник перед споживачем».
- Передбачувано для типової ментальної моделі секвенсера.
- Антипатерни задокументовано у `usage/02_writing_recipes.md`.
